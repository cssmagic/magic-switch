<h1 align="center">Magic Switch</h1>

A macOS menu-bar utility that hands off Magic Keyboard, Magic Trackpad, and Magic Mouse between two Macs with one click — no KVM, no cables.

***

## About This Fork / 关于这个 Fork

This fork is intended for and tested only with the first-generation Apple Magic Trackpad (Bluetooth wireless touchpad, powered by two AA batteries).

这个 Fork 仅适用于第一代苹果妙控板（蓝牙无线触控板/触摸板，采用两节 5 号电池供电）。

### Preparation / 准备工作

1. Pair the Trackpad with both Macs.
2. Connect both Macs to the same local network, install and run this app on both, and grant **Bluetooth** and **Local Network** permissions.
3. Open the app's Settings on both Macs, pair the other Mac as a peer, and register the Trackpad in the peripheral list.

<!-- -->

1. 把触控板分别与两台 Mac 配对。
2. 两台 Mac 连接到同一局域网，分别安装并运行本程序，开放 **蓝牙** 和 **本地网络** 权限。
3. 两台 Mac 分别打开本程序的设置界面，把对方配对为伙伴，并把触控板注册为可切换的外围设备。

### Daily Usage / 日常用法

1. Connect both Macs to the same local network, and run this app on both.
2. Connect and use the Trackpad on Mac A.
3. On Mac B, click the app's menu bar icon, and in the dropdown menu, click “Mac A” to switch the Trackpad's Bluetooth connection from Mac A to Mac B.
4. To switch it back, open the menu on Mac A and click “Mac B”.

<!-- -->

1. 两台 Mac 连接到同一局域网，分别运行本程序。
2. 在 Mac A 上连接并使用触控板。
3. 在 Mac B 上点击本程序的菜单栏图标，在下拉菜单中点击 “Mac A”，即可把触控板的蓝牙连接从 Mac A 切换到 Mac B。
4. 要切换回去，在 Mac A 上打开菜单，点击 “Mac B” 即可。
